# Sprint 5: Автотесты для Stellar Burgers

## Описание
Проект содержит 12 автоматизированных тестов для сайта Stellar Burgers, написанных на Python с использованием Selenium и pytest.

## Покрытие тестами
- **Регистрация** (2 теста): успешная регистрация и ошибка при некорректном пароле
- **Вход в аккаунт** (4 теста): через главную кнопку, личный кабинет, форму регистрации и форму восстановления пароля
- **Конструктор** (3 теста): переключение между разделами «Булки», «Соусы», «Начинки»
- **Личный кабинет** (2 теста): переход в ЛК и возврат в конструктор
- **Выход из аккаунта** (1 тест)

## Технологии
- Python 3.14
- Selenium 4.25
- pytest 9.2
- ChromeDriver
